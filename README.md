# my_agent_demo

## Overview

`my_agent_demo` is a sample project demonstrating how to build an AI-powered documentation agent using OpenAI's GPT models. The agent can read repository files, search code, and automatically generate and update documentation such as README files, API references, and contribution guides.

The repository contains a minimal codebase that showcases the core functionalities of the agent, including:
- File reading and writing utilities.
- Branch management and PR creation (simulated in this demo).
- Automated documentation generation based on repository contents.

## Usage

### Prerequisites
- Python 3.9+ installed.
- An OpenAI API key set in the environment variable `OPENAI_API_KEY`.

### Running the Agent
```bash
# Clone the repository
git clone https://github.com/your-org/my_agent_demo.git
cd my_agent_demo

# (Optional) Create and activate a virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the documentation agent (example command)
python -m agent.main --task update-readme
```

The above command will invoke the agent to analyze the repository and update the `README.md` with the latest overview, usage examples, and contribution guidelines.

### Example Output
After running the agent, you should see a new commit and a pull request created with the updated documentation.
